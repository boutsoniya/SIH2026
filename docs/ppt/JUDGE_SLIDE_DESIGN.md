# NARCOSCOPE — Slide Design System

## Visual direction
- Dark navy / white base with restrained cyan accents.
- One dominant diagram or visual per slide.
- Maximum 4–5 bullets.
- Use large numbers for workflow stages.
- Keep technical detail in speaker notes, not dense slide text.
- Use the same terminology as the product UI.

## Recommended slide layouts

| Slide | Layout |
|---|---|
| 1 | Full-width title + product visual |
| 2 | Problem cards + field photo/illustration |
| 3 | Solution architecture strip |
| 4 | Horizontal 7–10 stage workflow |
| 5 | Phone mockup + quality-gate callouts |
| 6 | Reference card diagram + calibration explanation |
| 7 | Decision funnel: usable → analyzed → presumptive / inconclusive |
| 8 | Evidence record anatomy |
| 9 | Offline → sync flow |
| 10 | QR scan → verification result |
| 11 | Field → FSL handoff |
| 12 | Security control stack |
| 13 | Prototype vs validation boundary |
| 14 | Impact + roadmap |
| 15 | Live demo checklist |
| 16 | Closing statement |

## Do not put on slides
- unsupported accuracy percentages
- fabricated datasets
- unvalidated sensitivity/specificity
- claims that ArUco identifies drugs
- claims that CIEDE2000 thresholds are universal
- claims that demo scenarios prove forensic accuracy

## Strong recurring visual
Use this as the bottom ribbon across technical slides:

**CAPTURE → VALIDATE → CALIBRATE → ANALYZE → SEAL → VERIFY → HANDOFF**
